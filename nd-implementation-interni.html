1. Preparation of requirements for web developers
Data Club
  • Basic SDK functionality requirements
  • DNS setup instructions
  • Definition and mapping of custom events
2. Web Implementation
DER Touristik ↳ Depends on: Phase 1
  • Client deploys SDK + DNS based on the provided instructions.
3. Blacklist Preparation
DC & DER ↳ Depends on: Phase 1
  • Blacklist expansion
    • Gathering email addresses, domains, and affiliate domains to blacklist from the client.
    • Identifying phone numbers for the blacklist.
4. Meiro Setup Completion
DC & Meiro ↳ Depends on: Phase 1, Phase 2
  • Meiro completes setup on their end
    • Once the client deploys the DNS records, we notify Meiro DEV to finalize the setup.
5. DC Implementation Check
Data Club ↳ Depends on: Phase 1, Phase 2, Phase 4
  • Review basic SDK initialization and correct event firing
  • Check custom_payload in page_view events
  • Thoroughly test all custom events
  • Feedback to the client (depends on implementation quality):
    • Basic feedback
    • Extended feedback and iterations in case of issues
6. Implementation in Meiro CDP
Data Club ↳ Depends on: Phases 1–5
  • Setup of each event in Meiro CDP
  • Setup of identity stitching rules
  • Preparation of attributes from web data
