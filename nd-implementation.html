    • Basic feedback
    • Extended feedback and iterations in case of issues
6. Implementation in Meiro CDP
Data Club ↳ Depends on: Phases 1–5
  • Setup of each event in Meiro CDP
  • Setup of identity stitching rules
  • Preparation of attributes from web data

Interní záloha původního zadání (Není určeno pro klienta)

  1. připravit zadání na nasazení SDK včetně custom events
    1. funkce základního SDK (1h)
    2. zadání pro nasazení DNS (0,25 h)
    3. definování a soupis custom events (2 - 3 h)
  2. klient - nasadit sdk + dns
  3. Rozšíření blacklistu (1,5 hodiny per country)
    1. zjistit od klienta, aby nám předal adresy, které chce blacklistovat + domény provizáků např.
    2. telefonní čísla pro blacklist
  4. meiro - dokončit (0,25 h per country)
    1. po nasazení DNS na straně klienta je potřeba informovat Meiro DEV, aby dokončili nastavení na straně ME
  5. DC kontrola
    1. projít základní inicializaci SDK a správné firování eventů (1 hodina per country)
    2. zkontrolovat custom_payload v page_view eventech (0,5 hodiny per country)
    3. otestovat pořádně všechny custom events ( 2 - 4 hodiny per country)
    4. feedback na klienta (závisí na tom, jak se implementace na webu povede, rozsah je tedy 0,5 hodiny per country až řekněme 6 hod per country, když to bude hodně špatně)
      1. základní feedback 0,5 hodiny per country
      2. v případě problémů více, z našeho odhadu 3 - 6 hodin per country
  6. DC - implementace v Meiro (events, stitching, attributes)
    1. setup každého eventu v Meiro CDP (2x) (10 minut per event + country)
    2. setup stitching rules (2x) (5 minut per event + country)
    3. příprava atributů z webových dat (2x) - pokud budou data 100% stejná, pak úpravy budou jednoduché
      1. All Checkout Steps — All stage of checkout process, includes purchase stage
      2. All Purchases — All purchase events collected by Meiro
      3. All Viewed Hotels — All hotels that the customer has viewed
      4. All Viewed Web Pages — All unique web pages viewed by customers
      5. Entry page — First page ever where customer entered the website
      6. Exit page — Most recent page where customer left the website
      7. Form Email submitted — All emails submitted from the web banner
      8. Google Client ID — All unique tracked Google client IDs
      9. Last Checkout Step — Last stage of checkout process, includes purchase stage
      10. Last Searched Tour Parameters_v3 — The 5 latest sets of parameters that a customer has viewed or searched for on Fischer.cz
      11. Last Visit — Datetime of last visit to nev-dama.cz
      12. Number of Events — Total number of events from website Nev-dama.cz for each customer entities
      13. Number of Page Views per Visit — Average number of pageviews per session
      14. Product Added to Cart — Product added to cart in the last 6 month
      15. Product Added to Cart (funnels; no time restriction) — Products added to cart with no time restriction
      16. Total Number of Visits — Total number of visits (sessions) made by customer
      17. Total Pageviews — Total pageviews from nev-dama.cz

Pokud budou data stejná, tak každý atribut 15 minut per jazyk. = celkem 8,5 hodiny

PM a komunikace 2 hodiny per country
Buffer na bugy / iterace po nasazení (2 hod per country)
